## Generation and changes

The files were generated by running `./gen_topo.sh 100km` with `USE_BGRID_MERGE=false` from [make_om3_topo commit `5de0f71e741c03b7adb554ebbea4110b3fdcc58f`](https://github.com/ACCESS-NRI/make_om3_topo/commit/5de0f71e741c03b7adb554ebbea4110b3fdcc58f) on 2026-10-13. This revision uses the same 100 km hgrid (2026.03.13) as the previous revision (2026.09.22) and raises `CUTOFF_VALUE` from 15400 to 17000.

`topog.nc` was produced using the sequence recorded in its `history` attribute: `topogtools gen_topo`, `topogtools min_dy --cutoff 17000`, `topogtools fill_fraction --fraction 0.5`, `editTopo.py --apply edit_100km_topog.txt`, `topogtools deseas --grid_type C`, and `topogtools min_max_depth --level 7 --vgrid_type mom6`. The hand edits in `edit_100km_topog.txt` are unchanged from the previous revision.

Compared with the previous revision (2026.09.22, `CUTOFF_VALUE=15400`), 23 ocean cells become land, and no land cells become ocean. Depths in all other ocean cells are unchanged. The 23 cells are:
- 17 cells in Foxe Channel (65.1–66.4°N, 80.5–83.7°W), which held the smallest cells on the grid. Foxe Basin remains ocean and connected.
- 6 cells at the southern end of the one-cell-wide channel in Victoria Strait / Queen Maud Gulf (69.4–69.8°N, 100.2–102.0°W). These include the cell at global index (i, j) = (169, 323), 1-based, where a CICE `negative area (ice)` abort occurred.

The number of ocean cells falls from 71,291 to 71,268, and the smallest ocean-cell spacing, min(dx, dy), rises from 15.6 km to 17.2 km.

`topog.nc` is a 360 x 324 C-grid topography with minimum depth 10.43281 m, minimum 7 vertical levels, and maximum depth 5808.657 m. `kmt.nc` is derived directly from `topog.nc` using `topogtools mask` in the same run and has matching 360 x 324 dimensions.
