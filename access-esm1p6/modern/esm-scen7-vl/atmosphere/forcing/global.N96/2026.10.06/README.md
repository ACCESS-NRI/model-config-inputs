### File List

- CO2_fluxes_vl_2022_2150_cmip7.anc             CO2 emissions ancillary file

### Data Specific Information

CO2_fluxes_vl_2022_2150_cmip7.anc contains gridded time varying CO2 fluxes to the atmosphere in kg(CO2)/m2/s, for use in the CMIP7 esm-scen7-vl experiment. This file contains additional padding data for 2021 and 2151, as required by the UM's time interpolation. However, it should only be used for simulations from 2022-2150.


## Methodological information

Copied from /g/data/tm70/pcl851/CMIP7/esm1p6_ancil/2026.10.06/modern/esm-scen7-vl/atmosphere/forcing/global.N96/2026.10.06/CO2_fluxes_vl_2022_2150_cmip7.anc. This file was generated using commit 5b54f0f during the pull request https://github.com/ACCESS-NRI/CMIP7-Input/pull/157. This 2022-2100 data are produced using the IIASA-IAMC-scen7-vl-1-1-1 and IIASA-IAMC-scen7-vl-1-1-2 data for non-air and aircraft emissions respectively. The 2101-2150 extension data are produced from the IIASA-IAMC-vl-ext-1-1-1 and IIASA-IAMC-vl-ext-1-1-2 datasets for non-air and aircraft emissions respectively.
