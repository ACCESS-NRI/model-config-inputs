### Data Specific Information

The file contains 12 months of climatological gridded nitrogen deposition data. Units for the nitrogen deposition are g(N) m-2 day-1.

## Methodological information

12 months of data are extracted from the 2021 values in the historical experiment nitrogen deposition ancillary (/g/data/vk83/configurations/inputs/access-esm1p6/modern/historical/atmosphere/land/biogeochemistry/global.N96/2026.03.27/Ndep_1849_2023_cmip7_v2_0.anc) using mule. The following values have set in the file headers to ensure that the model treats the file as a periodic climatology:

    ff.fixed_length_header.t1_year = 2021
    ff.fixed_length_header.t2_year = 2021
    ff.fixed_length_header.time_type = 2 
    ff.integer_constants.num_times = 12
    ff.fixed_length_header.t3_year = 0
    ff.fixed_length_header.t3_month = 1
    ff.fixed_length_header.t3_day = 0
    ff.fixed_length_header.t3_minute = 0
    ff.fixed_length_header.t3_second = 0
