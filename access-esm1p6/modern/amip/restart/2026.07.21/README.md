## Methodological information

This restart directory is copied from the 1978 restart file produced by the first member of the CMIP7 ESM1.6 cocentrations driven historical experiment, historical-1.1-r1i1p1f1, located in `/g/data/p73/archive/CMIP7/ACCESS-ESM1-6/production/ensemble-concentrations-historical/historical-historical-1.1-r1i1p1f1-01409bc3/historical-historical-1.1-r1i1p1f1-01409bc3/restart127/`. Ocean, sea-ice, and coupler restart files have been removed, and coupling related fields have been removed from the atmosphere restart file `restart_dump.astart` following the process described here: https://forum.access-hive.org.au/t/create-an-amip-restart-from-a-coupled-restart/5261
