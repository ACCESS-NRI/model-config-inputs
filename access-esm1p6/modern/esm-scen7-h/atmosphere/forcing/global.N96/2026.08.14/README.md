### Data Specific Information

CO2_fluxes_h_2022_2100_cmip7.anc contains gridded time varying CO2 fluxes to the atmosphere in kg(CO2)/m2/s, for use in the CMIP7 esm-scen7-h experiment. This file contains additional padding data for 2021 and 2101, as required by the UM's time interpolation. However, it should only be used for simulations from 2022-2100.
