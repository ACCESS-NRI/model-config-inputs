## Data and Files

### File List

- TSI_CMIP7_ESM            Solar forcing
- volcts_cmip7.dat         Volcanic forcing given as optical depths for 550nm, multiplied by 10000.


### Data Specific Information

The solar forcing file contains yearly mean total solar irradiance at 1 astronomical unit from the sun in units W m-2.
The volcanic forcing is provided as optical depths for 550nm multiplied by 10000 in the four latitude bands 30-90, 0-30, -30-0, and -90-0 degrees.


## Methodological information

Files were originally copied from /g/data/tm70/pcl851/CMIP7/esm1p6_ancil/2026.08.02/scenarios/h/atmosphere/forcing/resolution_independent/2026.08.02/,  which were produced using the ancillary generation code in https://github.com/ACCESS-NRI/CMIP7-Input/pull/135. The data outside of 2022-2100 has been manually removed. The solar and volcanic forcings were generated from the SOLARIS-HEPPA-ScenarioMIP-4-6 and UOEXETER-ScenarioMIP-2-2-2 data published by Input4MIPs respectively.
