## Data and Files

### File List

- BC_vl_2022_2100_cmip7.anc          Black carbon anthropogenic emissions
- OCFF_vl_2022_2100_cmip7.anc        Organic carbon (OC) anthropogenic emissions
- Bio_vl_2022_2100_cmip7.anc         Fire emissions of OC and BC
- scycl_vl_2022_2100_cmip7.anc       SO2 anthropogenic emissions


### Data Specific Information

Each aerosol forcing file contains time varying gridded emissions data for 2022-2100, with an additional buffer year of duplicate data added to each end as required by the UM. Units for each file are:
- BC_vl_2022_2100_cmip7.anc: kg(C) m-2 s-1
- OCFF_vl_2022_2100_cmip7.anc: kg(C) m-2 s-1
- Bio_vl_2022_2100_cmip7.anc: kg(C) m-2 s-1
- scycl_vl_2022_2100_cmip7.anc:  kg(S) m-2 s-1

## Methodological information

Files are copied from /g/data/tm70/pcl851/CMIP7/esm1p6_ancil/2026.07.14/scenarios/vl/atmosphere/aerosol/global.N96/2026.07.14. These files were produced using the ancillary generation code in https://github.com/ACCESS-NRI/CMIP7-Input/pull/135 and are equivalent to the files described [here](https://github.com/ACCESS-NRI/CMIP7-Input/pull/135#issuecomment-5161113497). The ancillaries were generated from the IIASA-IAMC-vl-1-1-1 data published by Input4MIPs.


The sulphur emissions file scycl_vl_2022_2100_cmip7.anc includes a field for climatological anthropogenic DMS emissions which is duplicated from the ESM1.5 file /g/data/vk83/configurations/inputs/access-esm1p6/modern/pre-industrial/atmosphere/aerosol/global.N96/2025.06.04/scycl_1850_cmip7.anc.
