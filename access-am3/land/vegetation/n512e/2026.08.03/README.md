## Data and Files

### File List

- qrparm.veg.frac: Vegetation area fraction.
- qrparm.veg.frac.nc: netcdf version of the vegetation fraction. Provided for convenience, not used by the model.
- qrparm.veg.func: Canopy height and leaf area index (LAI).
- qrparm.veg.func.nc: netcdf version of the canopy height and LAI file. Provided for convenience, not used by the model.
