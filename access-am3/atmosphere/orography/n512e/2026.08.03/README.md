## Data and Files

### File List

- qrparm.ash: Orographic form drag, fixed in time.
- qrparm.ash.nc: netcdf version of the orographic form drag. Not used by the model, provided for convenience
- qrparm.orog_mean: Orographic mean height, fixed in time.
- qrparm.orog_mean.nc: netcdf version of the orographic mean height. Not used by the model, provided for convenience
- qrparm.orog_radiation_parameters: Various parameters to complete the orographic information for the atmosphere.
- qrparm.orog_radiation_parameters.nc: netcdf version of the orographic parameter file. Not used by the model, provided for convenience
- qrparm.orog_wavedrag: Orographic wave drag information, fixed in time.
- qrparm.orog_wavedrag.nc: netcdf version of the wave drag file. Not used by the model, provided for convenience
