## Data and Files

### File List

- qrclim.rivstor: Mean river routing storage.
- qrclim.rivstor.nc: netcdf version of the river routing storage file. Provided for convenience, not used by the model.
- qrparm.rivseq: River routing sequence and direction
- qrparm.rivseq.nc: netcdf version of the sequence and direction file. Provided for convenience, not used by the model.
